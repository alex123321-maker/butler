# Research provenance checks

Pure bounded checks of quoted evidence against actual current-run read receipts.
WebFetch, URL-only extraction, HTTP GET and browser page observations are DATA;
search snippets, failed reads, inline extraction input and frozen local browser
preparation cannot establish page evidence. A source-role attribution remains a
model judgement. It is never an institutional authority certificate.

Unsupported-citation feedback prefers reuse of sufficient current-run browser
or HTTP evidence. Repair must also remove/correct unsupported claims and links;
it cannot convert a frozen local snapshot into external evidence or a write
receipt. The package neither fetches another page nor rewrites the answer.

The Orchestrator owns repair and budgets; Communication owns transactional
scheduled observations and delivery. This package performs neither network calls
nor policy authorization. See the [research contract](../../docs/architecture/research-followups.md).
