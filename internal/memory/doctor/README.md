# Memory Doctor

Read-only, owner-authenticated observations of PostgreSQL stores, source restore
authority, auxiliary jobs, semantic generations and the actual startup composition.
Each database probe is bounded; missing observations remain unknown, with no
fabricated zero backlog, policy count or usage. Raw errors and source text are
excluded. Existing answer quality remains unverified without an applicable report.

`effective_features` separates requested flags, constructed handlers/read services,
code-owned release qualification and supported native profile. `composed` means
these startup conditions hold, not a live worker, an authorized job, a healthy
provider or accepted answer quality. The configuration digest includes these
conditions, independently of slice order. It cannot be an activation credential.

`experience` describes the actual background generation handler and requires the
global model-jobs flag. `experience_context` describes the actual constructed
experience read/context store; it depends on its own enabled flag, qualification
and supported profile, independently of global jobs. An absent store is never
reported as wired. Temporal facts and Profile/Episode context annotations use
the same measured-profile readiness predicate. Expiry and captured-source guards
remain active independently of optional annotation/read composition.

`owner_policies` freshly observes the global durable model-worker control and
aggregate states of the authenticated owner's policies for the composed consumers.
Expired and exhausted counts can overlap active/paused/revoked states. Counts
include no policy IDs, sources, text or another owner's policies. They are metadata,
not proof of current source/task permission, remaining budget, a satisfied trigger
or successful admission. The owning job worker checks those on every attempt.

Flags cannot bypass a failed release gate. Disabling a handler does not erase
attempts, unknown usage, reservations, accepted facts or derivative source guards.
Operator rollback must keep current source and deletion-anchor checks installed.
