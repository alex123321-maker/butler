## Changes

- Current-goal instructions replace the shared list of all special tasks. The
  unknown-effect URL appears only for an actual unknown-action task, validation
  only for ready=maybe, preparation/check steps only for an artifact request,
  and the three-part procedure guidance only for procedure tasks. Historical
  uncertainty is distinguished from an unknown external action. A/B/C receive
  identical paired instructions; random verifier answer values are never inserted.
- New **V3** scoring requires a complete sufficient support alternative but allows
  extra exact, currently permitted, actually opened citations. An unread, wrong,
  stale, duplicate or foreign citation still fails; a distractor alone cannot
  supply missing required support. V1/V2 keep exact-set scoring, including their
  old empty-set behavior. V2 current-artifact semantics also remain intact.
- V3 observes actual `http.request` only for the same bounded synthetic current-
  project GET: method/url only, exact destination/path, goal-appropriate query,
  complete output, actual Broker action/result/dispatch evidence and ordinary
  recipient/source validation. This does not qualify arbitrary HTTP requests.
- Optional read limits now return **`limited` plus a fixed `limit_reason` and no
  DATA through the real Broker**, instead of invoking the whole-run budget stop.
  The owning reader rechecks durable history and current exact dispatch, task,
  input, lease, source and pinned applicability before returning a refusal.
  No extra DATA lookup or semantic reservation occurs. Another permitted current
  action or honest final may proceed under the existing shared budgets. Refusals
  spend normal allowances and cannot reset discovery after restart/refining.
  A limited read is not an empty lookup or negative fact about the current task
  or original action. Wrapped/mixed state, authority and storage failures remain
  fatal. Read contract revision3 must match between Broker and Orchestrator;
  existing exact contract bindings are not silently rebased.
