На **ssh laba** завершены **57/57 стадий, 48/48 контролей**, по два повторения
восьми случаев. Неисполненных стадий нет: 49 завершены, 8 неуспешны.
Collector exit 0 означает завершение сбора, а не успех всех задач. **#115 остаётся

## Качество и полная известная стоимость

Критерий прежний: проверенный текущий артефакт/наблюдение и соответствующий ему
ответ. Завершённый run, загрузка навыка и честный UNKNOWN сами по себе не
доказывают выполнение задачи. Оценку выполнял автор; независимой квалификации нет.

| Вариант | Задачи v5 → v6 | Полные известные tokens v5 → v6 | Новый неизвестный usage |
| --- | ---: | ---: | ---: |
| A: без опыта |14/16 →13/16|482514 →468447|1|
| B: общие замороженные notes |14/16 →13/16|1460558 →668843|1|
| C: те же notes + навык/инструкция |13/16 →14/16|1329435 →1142293|0|

Внутри нового окна **B−A: 0 дополнительных задач, +200396 известных tokens**;
**C−B: +1 задача, +473450 известных tokens**. Дополнительный успех C приходится
на случай, где B получил HTTP400, поэтому это не доказательство пользы навыка
для качества. A по-прежнему имеет наименьшую известную стоимость.

Три изменившихся исхода относительно [закрытого v5](../guided-full-v5/README.md):

- B37 и A38, `control-02`, второй проход: HTTP400 `provider_protocol_error` /
  `upstream_invalid_argument` при `tool_result`. Run завершён неуспешно,
  ExecutionResult отсутствует; его не подделывали. Usage неизвестен, резерв
  не возвращён. Это не ошибки `memory.search/open`.
- C43, проверка потерянного эффекта: новый run завершён, два поиска штатно
  вернули `empty`, текущий verifier действительно вернул503. Новая подготовка
  не выполнялась, UNKNOWN сохранён. Прежний failed C43 и его NULL не изменены.

Все шесть `control-03` остаются неуспешными: одна разрешённая попытка подготовки
даёт `effect_unknown`. UNKNOWN/отсутствие эффекта не доказывают поддержку либо
неподдержку `ready=maybe`. Эту задачу нельзя засчитать как выполненную.

Полные суммы строк используют прежнюю базу сравнения: S+Q(A), S+N+Q(B),
S+N+K+Q(C). S — исходные задания (95497 токенов), N — notes (27422), K — создание
навыка (183964). Контрольные Q(A/B/C): 372950/545924/835410 токенов. Общая подготовка
фактически выполнялась один раз; суммы строк нельзя складывать как уникальный
расход. Provider TotalTokens включает наблюдаемый thinking, а не только input+output.

Новый уникальный **известный** расход — 2061167 токенов против 3058291 в v5:
нижняя граница уменьшилась на 997124, или 32,60%. Два новых usage неизвестны;
точная полная стоимость и денежная экономия **не установлены**. Invoice cost
остаётся `unknown`; нулевые денежные units в политике подписки не являются счётом.

## Что произошло с чтением и навыками

В 48 контролях чтения сократились **73 →21**: B — 8, C — 13, A — 0.
Теперь 7 поисков (5 `ok`,2 `empty`) и 14 открытий (`ok`), все инструменты завершены
штатно. Нет memory-tool UNKNOWN, `memory_source_stale` и неприменимых загрузок.
**Четыре настоящих Broker skills.load** соответствуют текущим task/run,
task/constraints revision и digest pins PostgreSQL; все до первого проектного
действия, только repeat/similar C в двух проходах. Drift, beta-only, inspect-only
и удалённый источник не дали завершённой загрузки неподходящего навыка.

Главное сокращение B — два неудачных пути: 48 →12 модельных обращений,
908623 →126292 известных tokens,45 →8 чтений. Их итог всё ещё неуспешен.
Читать UNKNOWN дольше не означает получить отсутствующее доказательство.

Лимиты 24 model/32 external calls и 1276 новых native entries не повышались.
Дополнительная политика 8 чтений/3 поисков/2 последовательных поисков без новых
версий и запрет полностью повторного диапазона сохранены. В контролях максимум
8 model entries и 7 external calls; **защитная остановка чтения не сработала ни
разу**. Поэтому нельзя приписывать сокращение расходов непосредственно
срабатыванию потолка. Новая инструкция/указатели, заново созданный опыт, исправление
C43, вариативность модели и два HTTP400 не изолированы друг от друга.
