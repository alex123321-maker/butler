## Prospective observation boundary

Before starting the ordinary worker, snapshot the actual already-admitted
pending Input cohort plus the actual owner input. Its IDs come from durable
fixture rows, not model proposals or expected actions. The declared fixture has
no tool that admits new owner Inputs; Controller continuation inputs are already
admitted before evaluation. Preserve ordinary per-session FIFO and concurrency.

A successful owner outcome, a nonfatal failed/blocked/expired/cancelled owner
outcome or pre-input owner denial does not by itself cancel unrelated admitted
automatic execution. Observe that same cohort until queued/running execution is
quiescent within the existing original fixture/parent deadline. Preserve owner
status, IDs, final and automatic outcomes separately. Genuine blocked/waiting
records are not completed, resumed, removed or used to grant new authority.

The shared native sealed flag still causes an immediate safety stop with actual
partial/cancelled automatic evidence retained. Provider errors still globally
seal; no protocol-error advance, retry, seal clearing or fabricated final is
introduced. Source/ownership/journal failure and parent deadline remain fatal.
If quiescence cannot be evidenced within the existing bound, retain failure and
unknowns; no task/window/mandate allowance is extended or refunded.

This fixes observer cancellation, not agent language understanding. The public
scripted regression is infrastructure evidence only. Native results will still
be scored against unchanged per-turn expectations, using actual owner and
automatic final/effect/expense records and the original full denominators.
