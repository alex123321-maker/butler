## Unit and default

The local-stop unit is one original episode-arm, including its actual owning
task tree, every actual session/input/run in the fixture cohort, and any
automatic continuation. Stop the whole isolated variant, not merely the last
owner reply or one child. Independently coexisting tasks within that variant
must not keep running after its local barrier. Do not manufacture an owner Stop,
rewrite task status, mark inputs complete, bypass FIFO or release/reseed state
to obtain another response. Durable task/input states remain what the ordinary
kernel actually produced.

Default and all historical entry points remain strict global stop. Fixture-local
mode must be an explicit trusted experiment-admission enum bound to a NEW
window identity, public amendment hash and frozen manifest. It must not come
from model text, a tool response, corpus expectations, an arbitrary user payload
or an unbound environment toggle. A missing/unknown mode is strict, not local.
No local flag clears an already raised global seal.

## Exactly one allowed local class

Only an actual, durably recorded `action_effects.state=effect_unknown` from the
declared synthetic recipient in the current admitted episode-arm may trigger
fixture-local stop. Correlate it to the actual window/run/input/intent/tool/
authorization/dispatch and owned fixture. Retain that evidence and any failed
read diagnostic, recipient receipt, partial output, object state and UNKNOWN
usage. A deterministic rejection reason is useful evidence, not permission to
change the Broker's effect state. A model's summary is never a classifier.

Failure to read or correlate the journal is a GLOBAL failure. An UNKNOWN with
foreign/cross-fixture identity, an undeclared real recipient, evidence of escaped
effects or an uncertain isolation boundary is GLOBAL, even if another local
UNKNOWN exists. Known actor/object scope mistakes may be observed as failures;
they must not be prevented by changing the hidden input or granting authority.
Durable transactional rejection diagnostics may explain a bounded synthetic
outcome; they do not make an unauthorized proposal or incomplete task pass.

## Global conditions, with priority

Provider/authentication errors, true incomplete provider operations, source or
ownership/task-authority observation unavailability, stale authority, journal/
counter/hash corruption, unclassified runtime or fixture errors, isolation or
quiescence failure and original resource/deadline/cap breaches remain GLOBAL.
The ordinary kernel continues to fail closed. Preserve task/tree Stop,
revocation, currentness, CAS, idempotency and provider continuity boundaries.
No larger timeout, alternative provider/account, grant or hidden retry follows
from selecting local UNKNOWN scope.

A known, intentional cancellation made solely to enforce an already durable
local UNKNOWN barrier can be labelled `cancelled_by_fixture_local_stop` in the
research journal. It is not a successful provider operation: retain its partial
events and nullable usage. That narrowly identified cancellation must not hide
a concurrently observed provider error, watchdog cancellation, stale-source
failure or failed evidence write, all of which have global priority. An
ambiguous cancellation cause is GLOBAL. No arbitrary `context.Canceled` or clean
channel close is sufficient to infer an intentional local stop.

A legitimate single-tool proposal hands control to the Broker; its per-operation
stream can close without `run_completed`. Validate that handoff against the
actual transport contract. It is distinct from an empty/run_started-only close,
partial unfinished response, unsupported batch, cancellation or provider error.
Do not globally seal a legitimate correlated tool handoff, and do not treat an
unsupported/malformed stream as one merely because a tool-looking field exists.

## Local barrier, quiescence and next scheduled fixture

1. Record an immutable local-stop decision with actual window/arm/run/input/
   effect/dispatch identities, observed time, cause and prospective mode/hash.
   Atomically close that arm's admission before another model call or tool
   dispatch is admitted. Define and test one lock/order/barrier rule for races
   with concurrent automatic and owner runs; a poll alone is insufficient.
2. Stop admission and workers for the whole fixture cohort. Preserve already
   admitted calls and their actual completion/cancellation, effects and costs.
   Never retry, resume blocked work or run the remaining planned owner message.
   A prospective bounded cleanup may observe/quiesce; it cannot extend original
   authority or permit a new effect. Cleanup/evidence failures stop globally.
3. Join workers/provider streams and prove no active claim/lease, in-flight
   provider/runtime call, recipient transaction or live Broker process can act
   for the closed fixture. Merely setting a flag or cancelling a context is not
   a quiescence receipt. Preserve queued/blocked/waiting rows; they are not
   falsely terminalized. If an actual kernel lease/claim cannot be safely
   released by its owner within the unchanged bounds, stop globally.
4. Export independent after-state and all durable journals, source-consumer
   proofs and exact deletion-anchor bytes/watermark. Seal/hash the local outcome
   before starting the next scheduled fixture. Preserve original native limits,
   unfinished kernel reservations and unavailable usage; no allowance refund.
5. Mark the remaining original steps/opportunities in this arm
   `not_executed_after_fixture_local_unknown`, with the stopping action reference.
   Distinguish them from never-started fixtures, actual expected admission
   denials, model refusals, malformed finals and technical failures. No synthetic
   final, before/after effect or owner verification is invented for that tail.
6. Only then start the NEXT original scheduled independent fixture, with its own
   schema/recipient/session/anchor/authority and ordinary fresh task IDs. Never
   reseed or replay the stopped arm, choose a different answer/case, reorder the
   paired arm, compensate with extra cases or filter the stopped pair away.

Shared host services/control accounting do not by themselves prove isolation.
Public tests must demonstrate zero cross-fixture admission/effect/queued-worker
reach after local stop, including intentionally delayed automatic work and a
runtime reply racing the barrier. Export process and fixture identities; retain
global precedence under a simultaneous source/provider/journal error.

## Gates before fresh authorship and admission

First independently review/freeze the public fixture and protocol semantics;
only then author substantively new hidden controls under the fixed families and
thresholds. No old started-case replay or candidate/quality tuning is allowed.
After authorship permit literal path/hash/admission bindings only, followed by
independent zero-native setup/composition and a final exact producer/ELF pin.

Required public scripted, real-PG/Core/Broker gates include:

* Strict default foreign GET -> actual original UNKNOWN -> global stop -> next
  callback denied; the new local mode must not alter this historical/default
  path or turn a failed tool into confirmed success.
* Explicit local mode -> actual UNKNOWN -> owning cohort/arm barrier and exact
  remaining-tail classification -> independently quiescent fixture -> exactly
  next original fixture callback. No same-arm continuation or delayed effect.
* Provider/auth/source/task-authority/journal/isolation errors globally stop in
  BOTH modes, including when racing or following a local UNKNOWN. No global
  flag reset, normal context cancellation exemption or swallowed error.
* Legitimate measured tool handoff -> correlated SubmitToolResult -> actual
  final; empty, run_started-only, partial, cancelled/error and invalid batch
  streams remain distinguishable without invented usage/version.
* Waiting and blocked/queued FIFO are observed without state writes; delayed
  automatic work is joined; worker early return and cleanup are bounded.
* Phase-specific safe authority tracing records pool acquisition, remaining
  shared750ms watchdog deadline after lease read, transaction/query family/hash,
  SQLSTATE and cancellation cause with scripted provider. The reserve already
  exists. Historical authority latency cause remains unknown until reproduced;
  do not claim this amendment fixes it or widen the guard to make it disappear.
* Success/rejection/CAS/lost-ACK matrix with durable bounded recipient diagnostics,
  exact source-consumer tables/anchor backups, all-history equality and per-call
  operation/admission/usage accounting. Run full fresh zero-native composition
  only after the semantic fixture freeze.

Freeze new absolute deadlines and cost/call limits prospectively and separately
from closed windows. A new independent admission decision is still required
after all gates. Neither the owner's failure-scope choice nor this amendment
authorizes inference, closes issue76, or guarantees completion of a future study.
