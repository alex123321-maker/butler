# Prospective local-tail mechanical scoring composition

This composition is frozen before new hidden authorship. It uses no old/new
mapping and embeds no linguistic case or expected response. Existing controls,
goldens, scorers and masked judgments remain unchanged.

`local-scoring-composition-v1.ps1` exposes `Invoke-Issue76LocalScoringFiles`.
It verifies independently pinned stimulus and golden bytes, then calls the
frozen local-tail parser. Only the exact original source of
`score-mechanical-fresh-v3.ps1` (SHA256
`e481f9c062a3bc4500b9f0b94da8819fbf287bec075490583cad17d54198721d`)
may supply criterion code. Its original AST function definitions and complete
criterion statements are extracted and invoked unchanged. The accompanying
extent manifest records original line positions and SHA256 for every imported
function/statement. No stimulus, golden or model text is evaluated as code.

Actual executed steps use their original before/after/outcome/table references.
Their original snapshot, object/version, profile/restart, owner-final,
clarification/action/profile-proposal, actual final verdict, mutation/CAS/
receipt and matrix criteria are invoked from the pinned original source.
Actual automatic finals and late admitted effects remain in those tables.
The real public ordinary fixture produces exactly the same check IDs, kinds,
verdicts, actual/expected values and evidence references as running the complete
byte-identical original scorer against that same public fixture.

The prospective changes are traversal and availability only:

* Validate local barriers/identities/quiescence before scoring. On a valid tail,
  branch before resolving snapshots and before expected-denial criteria.
* Keep all96 owner and semantic opportunity rows, including missing arms,
  unrecorded steps, unusable actual finals and unexecuted local tails.
* Invoke the original evaluated-owner loop over only actual executed steps.
  A skipped expected denial remains unavailable. An actual expected denial
  requires the original denial and zero-native checks, and stays distinct.
* Require the original last after-snapshot for final target-state criteria;
  never substitute an earlier observed snapshot. Missing final state is
  unavailable. Requirements tied to a skipped event/read/restart/Stop are
  unavailable rather than false/pass inferred from absence.
* For an incomplete episode, observed absence of task controls/owner
  verification cannot establish whole-episode absence. Preserve the observed
  check and annotate unavailable. Actual observed failures remain failures.
* An incomplete after-Stop count cannot pass from an empty tail. Preserve any
  observed monotonic excess above the original threshold as failure; otherwise
  retain unavailable. The original comparator/threshold is unchanged.
* Retain every actual UNKNOWN separately with `success=false`; it never
  supplies successful critical evidence. Unclassified/foreign late UNKNOWN is
  rejected by the parser. A local stop does not erase an observed unsafe final
  or uncertain commit.

No fabricated v1 index/snapshot is used in actual scoring. The public parity
selftest alone creates a separate v1 *public test index* referring to the same
real public test snapshots so the old program can be compared directly.


The independent pins include window, producer, protocol, stimulus, golden,
manifest and index SHA256. Authorship changes only literal file/hash bindings;
it cannot change this branch, imported criteria, thresholds or public tests.

The result deliberately leaves communication, full source/effect correlation,
promotion and issue closure unassessed. Mechanical checks are evidence for the
independent complete rubric, not a substitute for those audits or a second
native admission. Parser PASS or48 indexed dispositions do not mean96 executed
or successful owner responses. Closed historical failures/costs remain intact.
