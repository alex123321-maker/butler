# Prospective local-model checker v2 implementation

These are new files; all historical v1 parser/composer/scorer and v2a authority
reader/stream-entry files remain exact. No closed study is reinterpreted. The
owner-approved change applies only to a newly frozen and separately admitted
study. No hidden corpus or native admission is established by these components.

## Entry points and dependencies

- `local-model-proof-reader-v2.ps1`: typed content-free failure proof helpers,
  loaded and hash-pinned by the new adapter.
- `local-tail-adapter-v2.ps1`: `Read-Issue76LocalEvidenceV2`. Requires new index
  `behavior76-checker-index-v3-local-model-tail`, explicit manifest flag
  `whole_fixture_after_exact_empty_answer_v1`, and binding mode
  `fixture-local-model-v8`. Existing effect UNKNOWN proof remains unchanged;
  its new DDL native_evidence:null is accepted. A model cause instead requires
  the exact non-null native_evidence union member.
- `local-scoring-composition-v2.ps1`: `Invoke-Issue76LocalScoringFilesV2` or
  `Invoke-Issue76LocalScoringV2`. Loads the exact old criterion source and extracts
  its original functions/27 statement extents by their original byte hash.
- `authority-stream-scoring-v2b.ps1`: `Invoke-Issue76StreamScoringFilesV2`.
  Prevalidates the original actual compressed stream with the unchanged frozen
  `authority-stream-reader-v2a.cs` and its PowerShell loader, then invokes v2
  composition. No fake flat trace or snapshot is generated.

The file entry accepts ReportRoot, StimuliPath, GoldensPath, Pin,
FrozenScorerPath, AdapterPath and CompositionPath. The Pin keeps the existing
window/producer/protocol/stimuli/golden/manifest/index hashes and additionally
binds `attempts_sha256` and `windows_sha256` to the already independently sealed
root journal JSONL bytes. This is checker input binding, not a new Go/runtime
field, authority grant or operational study gate. Whole-file sealing is still
audited independently before any composition.

Native evidence is compared against the actual immutable window+n row, nullable
usage/version and exact event chain. Actual run/Input/task/session joins and
owner witnesses are required. Reservation IDs are unique/contiguous against the
actual closed window counter. No same-arm admission may follow the durable
barrier/cutoff. All current-arm terminal errors are checked; an earlier local
stop does not excuse a different later failure. Both first-cause orders and late
classified UNKNOWN/native failure observations remain represented.

Strict usage fields are InputTokens/OutputTokens/TotalTokens, optional
ThinkingTokens; null objects, strings, aliases and arbitrary fields are rejected.
Observed native version follows the unchanged Gemini parser shape. Empty/absent
usage remains NULL; no zero, estimated billing or invoice cost is invented.

## Scoring and limits

The existing mechanical expressions remain unchanged on actual observations.
New native-response failure references add an explicit failed/non-success outcome
under the newly approved stop policy. If the exact owner run failed without an
authoritative owner final, its response disposition is failed and language
judgment unavailable. An automatic failure retains any actual owner final for
the old checks. Model failure never deletes earlier authority/effect/profile/
completion violations or turns critical UNKNOWN into success.

Every original tail opportunity remains unavailable, including expected-denial
tails; empty snapshot paths are not opened. All24/48/96/12 denominators remain.
An indexed local disposition is not a usable successful response or a quality
gain. Semantic judgments remain masked until sealed. Source freshness, authority,
deadlines/budgets, journal/hash, observer, isolation and quiescence faults remain
GLOBAL. Original bounds and quality thresholds are unchanged.

Public offline evidence comprises32 inherited adapter tests,47 new native-proof
tests,12 original composition equivalence/negative tests,7 model-composition
tests,6 original-stream/new-composition tests and2 cause-union tests:106 PASS.
No actual model, auth source, hidden control, mapping, old response or PostgreSQL
