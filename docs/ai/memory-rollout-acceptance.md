All cloud consumers require their measured High32768 output/five-minute profile
and actual matching budget. The durable model control still defaults disabled;
an enabled process has no job without a finite current owner policy. Adaptive
retrieval stays disabled after its retained NO_GO unless a future complete
independent comparison qualifies a specific version. Unsupported profiles cannot
be enabled by a stored setting or flag.

Rollback first pauses new background admission using the authenticated model
worker control, then disables the particular optional process flags and rebuilds
from the reviewed prior immutable image/config. Keep all current migrations,
privacy guards and the newest independent deletion anchor. Do not lower a
watermark, reset reservations/NULL usage or reactivate a stale summary/index/view.
Rollback of a derivative remains subject to exact current source and owner CAS.
Unknown external effects continue to require independent verification before
any retry; disabling memory does not undo an action.

## Operational limits

Doctor separates requested/composed/code-qualified/profile-supported state from
fresh durable worker controls, owner policy counts, provider availability and
answer quality. `composed` grants no admission. Unknown observations remain
unknown; an HTTP200, enabled flag or zero visible jobs is not a quality pass.

Owned indexing caps a scope at10000 chunks. Exact Store search at that target
passed the declared warm p95 bound;100000 in one scope missed the stretch bound.
Do not raise runtime caps from a bulk-vector experiment. Local embedding RAM and
device observations are service peaks, not a guarantee for concurrent workers.

Inspect jobs, failure reason, finite deadline and retained attempt before an
explicit retry. Queue/model/database outages must not manufacture a completed
job, accepted fact or refund. Interactive work has priority over optional model
jobs; test the actual final composition and queue contention before activation.

Owner `POST /api/v4/memory/index-retire` requires the exact inactive generation
and expected active pointer, terminal constructor-owned job, authenticated owner
and delivery identity. It removes only those vectors, preserves source/job/
quality/spend audit and irreversibly blocks later use or rollback. It remains
available without local inference. Retiring a derivative does not delete a
private original.

If the deletion-anchor disk fills, a failed append must not be reported as a
committed deletion. A partial append can make the anchor unavailable: memory
then fails closed, including restore reconciliation. Preserve the affected file,
PostgreSQL snapshot and diagnostics; restore/repair only from independently
verified operator-held anchor evidence. Never call Initialize on the old path,
truncate unknown records, substitute an empty file or reset a watermark to make
the service appear healthy. The lab ENOSPC test uses a dedicated8KiB tmpfs and
does not fill the server filesystem.

After real user workload exists, collect only explicitly permitted redacted
examples for independent human review and compare quality, current instruction
adherence, actual effect verdicts and full cost against this version's pilot.
Degradation blocks promotion or rolls back the affected optional function; a
mean quality score cannot compensate for a privacy/authority/currentness failure.

Migration079 down is allowed only before any irreversible run payload marker
exists. Once deletion has fenced a run, schema downgrade refuses to remove its
privacy fence. Roll back optional consumers/images while retaining migrations
and the independently held deletion anchor; never drop live deletion metadata.
